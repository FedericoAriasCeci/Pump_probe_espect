Hay que correr el programa desde Python (Spyder venimos usamos) corriendo el archivo
Codigo.py. Este archivo que contiene todo el código del programa posee comentarios para
explicar el código. 

La carpeta Pump and Probe Software puede copiar y pegarse (o cortar y pegarse) en otro lado
sin problema para la ejecución desde el Python. 

Las carpetas CSVs y Plots guardan los datos de las mediciones. Se van acumulando, así que
vendría bien ir borrándolas o grabarlo de otra manera. Los cuatro archivos data son para 
guardar la información recurrente a la configuración del programa.

Suele ocurrir que los USBs conectados a la PC no son detectados siempre. Cuando ocurre es 
necesario reiniciar la PC, suspenderla, o reconectar los USBs.
